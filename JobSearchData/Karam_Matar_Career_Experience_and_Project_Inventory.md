## 11. Glossary of Terms Used in the CV

- **CI/CD:** Continuous integration and continuous delivery/deployment, practices for testing and delivering code automatically.
- **SBOM (Software Bill of Materials):** An inventory of a software application's included dependencies and components, useful for security analysis.
- **E2E (end-to-end) testing:** Testing an entire user workflow instead of only a single function or component.
- **ORM (object-relational mapper):** A library such as SQLAlchemy or Prisma that maps application objects to database operations.
- **Database migration:** A version-controlled schema change, for example made with Alembic.
- **PostGIS:** A PostgreSQL extension that supports geographic/spatial data and queries.
- **S3:** Object-storage API used for storing and retrieving items such as imagery.
- **TIFF:** An image format often used for high-resolution or geospatial image data.
- **CFG (control-flow graph):** A graph representing possible paths of execution through a program.
- **IR (intermediate representation):** An internal form of a program used between source-code parsing and execution/code generation.
- **TAC (three-address code):** An intermediate-code style expressing computations in small instructions with a limited number of operands.
- **MCP (Model Context Protocol):** A protocol for connecting AI systems to tools and external context providers.
- **Reverse proxy:** A server such as Nginx that accepts incoming requests and forwards them to an application server.
- **Human-in-the-loop:** A workflow where people review or correct a machine-produced result before it is accepted.
